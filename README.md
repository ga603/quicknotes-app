# QuickNotes

QuickNotes is a simple note-taking web application that allows users to create, organize, search and delete notes. Notes can be categorized as Personal, Work or Study, and they are automatically saved in the browser using localStorage so that they remain available after refreshing the page.

## Features

- Add new notes
- Categorize notes as Personal, Work or Study
- Delete individual notes
- Search notes
- Validate empty notes
- Limit notes to 200 characters
- Display the number of saved notes
- Save notes using localStorage
- Restore notes after refreshing the page
- Responsive design for mobile devices
- Different visual styles for each category
