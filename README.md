# QuickNotes

QuickNotes is a simple note-taking web application that allows users to create, organize, search and delete notes. Users can categorize notes as Personal, Work or Study, and the application saves notes in the browser using localStorage so they remain available after refreshing the page.

## Features

- Add new notes
- Categorize notes as Personal, Work or Study
- Delete individual notes
- Search notes
- Case-insensitive note searching
- Validate empty notes
- Limit notes to 200 characters
- Display the number of saved notes
- Save notes using localStorage
- Restore notes after refreshing the page
- Responsive mobile-friendly design
- Different visual styles for each category
